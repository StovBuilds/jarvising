Jarvising MCP server: use this site from your AI assistant

jarvising.com now runs an MCP server. MCP (Model Context Protocol) is the open standard that assistants like Claude, ChatGPT, Cursor and VS Code use to connect to outside tools and data. Add the address below and your assistant can search the entries here, read any public page in full and list them newest first, so it can talk you through a teardown from the page itself rather than from memory.

It's free, needs no account or key, and is read-only: it can't change anything, and it only sees pages that are already public. The setup steps follow below.

The address

https://jarvising.com/mcp

It speaks MCP over Streamable HTTP. There is no sign-in, no API key and nothing to install on the site's side.

What your assistant can do with it

ToolWhat it does
search_siteSearches every page listed in the site's sitemap and returns the best matches, each with its URL, a short snippet and its last-updated date.
get_pageFetches one page from this site as clean text, with its title and last-updated date.
list_pagesLists the pages, newest first, a section at a time if you want.

All three only read. None of them can post, buy, sign up or change anything, and none of them can see a page that isn't already public.

Things to ask once it's connected:

  • "Search jarvising.com for the Cortex memory map."
  • "List the entries on jarvising.com, newest first."
  • "Summarise the Inside the Rig entry on jarvising.com."

How to connect it

Claude (claude.ai and the desktop app)

Open Settings → Connectors (in newer versions, Customize → Connectors), choose Add custom connector, name it Jarvising, paste the address above and leave the OAuth fields empty. The Free plan allows one custom connector.

ChatGPT

ChatGPT adds custom MCP servers through Developer mode: Settings → Apps → Advanced settings → Developer mode, then create an app with the address above and no authentication. Which plans get Developer mode has changed more than once, so if you can't see it, check OpenAI's help pages for your plan.

Claude Code

claude mcp add --transport http jarvising https://jarvising.com/mcp

Cursor

Add this to ~/.cursor/mcp.json (or .cursor/mcp.json in a project):

{
  "mcpServers": {
    "jarvising": { "url": "https://jarvising.com/mcp" }
  }
}

VS Code

Add this to .vscode/mcp.json:

{
  "servers": {
    "jarvising": { "type": "http", "url": "https://jarvising.com/mcp" }
  }
}

What we record

When a tool is called, we may count it: which tool, whether it worked, and a rough label for the kind of client (Claude, ChatGPT, Cursor and so on). We don't store what you searched for, which pages you asked for, your IP address or anything else about you.

Other machine-readable files

  • llms.txt: a plain-text map of the site for AI tools.
  • MCP discovery card: the server's address, transport and tools as JSON.
  • Sitemap: every public page, with last-modified dates. The MCP server indexes exactly these pages.
